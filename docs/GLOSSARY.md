# Glossary — Symbol Translation Registry

Anti-drift reference. Every renamed symbol gets registered here so later
sessions use identical names. Add rows as translation proceeds.

## Conventions (finalize Session 1)

- Hungarian prefixes stripped: m_iShares → shares
- Class prefix dropped: CCompany → Company
- Constants: SCREAMING_SNAKE_CASE preserved or converted to camelCase consts
- Function names: PascalCase methods → camelCase functions
